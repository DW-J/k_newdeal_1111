# Lingua Live

브라우저에서 음성이나 텍스트를 입력받아 Gemini로 세 언어에 번역하는 웹 앱입니다. 로컬 실행과 Vercel 배포를 지원합니다.

## 실행

Node.js 18 이상이 필요합니다. 시스템 환경변수 `GEMINI_API_KEY`가 설정된 터미널에서 다음 명령을 실행하세요.

```powershell
npm install
npm start
```

브라우저에서 http://localhost:3000 을 열고 마이크 권한을 허용하세요. 음성 인식은 Web Speech API를 지원하는 Chrome 또는 Edge가 필요하며 브라우저와 네트워크 환경에 따라 동작이 달라질 수 있습니다. 음성이 확정되는 단위로 번역이 갱신됩니다. 음성 인식은 브라우저의 음성 인식 서비스를 사용할 수 있으며, 인식된 텍스트는 번역을 위해 Gemini API로 전송됩니다.

`GOOGLE_API_KEY`도 대체 환경변수로 지원합니다. 필요하면 `GEMINI_MODEL`과 `PORT`를 설정할 수 있습니다. 서버는 로컬 컴퓨터에서만 접근할 수 있도록 127.0.0.1에 바인딩됩니다.

각 번역 카드에서 언어를 선택하고 번역 텍스트를 복사하거나 Gemini 음성을 생성할 수 있습니다. 음성 플레이어는 0.75배부터 2배까지 속도 조절을 지원하며, WAV 다운로드는 생성된 원래 속도의 음성을 저장합니다. 음성 생성에도 Gemini API 사용량이 발생하며 텍스트가 Gemini로 전송됩니다. TTS 모델은 `GEMINI_TTS_MODEL` 환경변수로 변경할 수 있습니다.

텍스트를 직접 입력하거나 UTF-8 TXT, Markdown, CSV, JSON 파일을 업로드한 뒤 **번역하기**를 누르세요. 입력은 최대 4,000자, 파일은 최대 16KB입니다. 각 번역 카드에서 TXT로 저장할 수 있습니다. 업로드한 파일의 텍스트는 번역을 위해 Gemini로 전송됩니다.

토큰 현황은 Gemini가 반환한 번역 및 음성 생성 사용량을 집계합니다. 로컬에서는 서버 프로세스의 누적값을 표시하며 서버 재시작 시 초기화됩니다. Vercel에서는 현재 브라우저의 로컬 저장소에 누적하며, 다른 브라우저와 공유되지 않고 저장소를 삭제하면 초기화됩니다. 사용량 정보가 없는 응답은 토큰 합계에 반영되지 않습니다. 어느 경우에도 계정 전체 사용량이나 요금 청구액은 아닙니다. 입력·출력·생각 토큰 외의 항목이 총계에 포함될 수 있습니다.

## Supabase에 번역 저장

번역 카드의 **저장** 버튼은 원문, 해당 카드의 번역문, 대상 언어, 저장 시각을 Supabase에 기록합니다. 복사와 TXT 저장은 별도 기능입니다.

1. 사용할 Supabase 프로젝트에서 `supabase/schema.sql`을 SQL Editor로 실행합니다. 이 앱이 사용하는 `saved_translations` 테이블을 만들며, 이미 같은 이름의 테이블이 있다면 구조를 확인한 뒤 적용해야 합니다.
2. 프로젝트 URL은 `config.json`에 설정되어 있습니다. 서버를 실행하는 환경에 `SUPABASE_SECRET_KEY` (서버 전용 secret key)를 설정합니다. 다른 프로젝트를 쓰려면 `SUPABASE_URL` 환경변수로 URL을 덮어쓸 수 있습니다. 기존 `SUPABASE_SERVICE_ROLE_KEY`도 지원합니다. 비밀 키는 브라우저나 소스 코드, 채팅에 공유하지 마세요.
3. 서버를 다시 시작합니다. 프로젝트의 Data API가 `public` 스키마를 노출하고 있어야 합니다.

비밀 키는 서버에서만 사용되며, 저장된 데이터는 Supabase 대시보드의 `saved_translations` 테이블에서 확인할 수 있습니다. 현재 배포에는 앱 자체의 사용자 인증이나 사용자별 접근 제어가 없으므로, 배포 주소에 접근할 수 있는 사람은 번역과 저장 기능을 사용할 수 있습니다.


앱의 배경음악은 Suno 플레이어에서 직접 재생하거나 일시정지할 수 있습니다. 마이크 인식과 번역 음성 재생 시에는 음악을 직접 잠시 멈춰 주세요. Suno 플레이어 접근에는 인터넷 연결이 필요합니다.

배경음악 영역에 Suno 곡 페이지 또는 공유 링크를 입력하고 **곡 불러오기**를 누르면 플레이어의 곡을 변경할 수 있습니다. 플레이어의 재생 버튼을 직접 눌러주세요. 공유 링크 확인에는 서버의 인터넷 연결이 필요하며, 곡 공개 설정이나 Suno의 플레이어 지원 여부에 따라 재생이 제한될 수 있습니다.

배경음악 입력란은 YouTube 동영상 링크(`youtube.com/watch`, `youtu.be`, Shorts, Live)도 지원합니다. YouTube의 동영상별 삽입 재생 정책에 따라 일부 곡은 앱 안에서 재생되지 않을 수 있으며, 이때는 **YouTube에서 열기**를 이용하세요.

첨부된 네 효과음은 선택, 시작, 성공, 오류 순서로 사용됩니다. 효과음 설정에서 켜고 끄거나 음량을 조절할 수 있습니다. 음성 인식 또는 번역 음성이 재생되는 동안에는 효과음이 재생되지 않습니다. 배경음악은 Suno/YouTube 플레이어에서 직접 조절해주세요.

앱 최상단에 배치한 푸터 컴포넌트는 `components/ui/doodle-crew-footer.tsx`의 React 컴포넌트를 사용합니다. 푸터 설정은 `components/footer-entry.tsx`에서 변경하고, `npm run build:footer`로 브라우저용 파일을 생성합니다. `npm start`는 푸터를 먼저 빌드합니다. 컴포넌트가 자체 스타일을 사용하므로 Tailwind나 shadcn 설정은 필요하지 않습니다.


## 개발 및 배포 과정

다음은 현재 앱을 만들고 확장한 순서입니다. 구현과 배포 작업은 2026년 11월 11일 대화에서 진행했습니다.

1. **기본 실시간 번역 앱 구성** — Node.js 서버와 웹 화면을 만들었습니다. 브라우저 Web Speech API로 말한 내용을 텍스트로 표시하고, 서버에서 `GEMINI_API_KEY`를 읽어 Gemini API로 세 언어에 번역하도록 연결했습니다. 키는 브라우저에 전달하지 않습니다. 기존에 시도한 Gemini 모델이 사용 중인 계정에서 제공되지 않아, 실제 요청으로 사용 가능한 모델을 확인하고 기본 번역 모델을 `gemini-3-flash-preview`로 설정했습니다.
2. **언어와 번역 결과 기능 추가** — 입력·번역 언어 선택지를 확대하고, 각 번역 결과에 복사 버튼을 추가했습니다. Gemini TTS로 음성을 생성해 재생하고 WAV로 다운로드할 수 있게 했습니다. 재생 속도는 0.75배부터 2배까지 선택하며 WAV 파일은 원래 속도로 저장합니다.
3. **텍스트·파일 입력 및 토큰 현황 추가** — 직접 텍스트를 입력하거나 UTF-8 TXT·MD·CSV·JSON 파일을 선택해 번역하고, 각 번역 결과를 TXT로 다운로드할 수 있게 했습니다. Gemini가 반환하는 토큰 사용량을 화면에 표시했습니다.
4. **Supabase 저장 기능 연결** — 번역 카드의 복사 버튼 오른쪽에 저장 버튼을 추가하고, 원문·번역문·대상 언어를 `saved_translations` 테이블에 기록하도록 서버 API와 `supabase/schema.sql`을 준비했습니다. 프로젝트 URL을 `config.json`에 설정하고 서버 전용 비밀 키를 환경변수에서 읽도록 했습니다. 초기 연결 확인에서 Supabase HTTP 401이 발생해 키 설정을 다시 확인하도록 안내했습니다.
5. **디자인과 기분 테마 적용** — 제공된 디자인 문서의 둥근 카드·버튼·여백 체계를 적용했습니다. 이미지로 제공된 어스톤 팔레트와 Arimo 폰트를 사용하고, 다섯 가지 기분에 따라 화면 색조가 바뀌도록 만들었습니다. 선택한 기분은 브라우저에 저장됩니다.
6. **배경음악과 효과음 추가** — Suno와 ElevenLabs의 당시 안내를 확인해 음악·효과음 제작 방향을 정리했습니다. 제공된 Suno 곡을 플레이어에 연결하고 Suno·YouTube 링크 입력 기능을 추가했습니다. 제공된 네 WAV 파일을 선택·시작·완료·오류 효과음 순서로 연결하고 효과음 켜기·끄기와 음량 조절을 추가했습니다. 마이크 인식 또는 생성된 음성이 재생되는 동안 효과음은 재생하지 않습니다.
7. **이미지 보드와 나뭇잎 모션 적용** — 첨부한 가을 이미지들을 참고해 로고·캐릭터·버튼 아이콘 보드를 제작하고 앱에 적용했습니다. 배경을 투명하게 만든 뒤 잘림을 줄이기 위해 4×4 정사각형 칸과 여백을 가진 `public/images/autumn-icons-grid.png`를 새로 만들었습니다. 나뭇잎이 천천히 떨어지는 모션을 `public/motion.css`에 분리하고 움직임 줄이기 설정을 지원했습니다.
8. **React 컴포넌트 적용과 화면 이동 개선** — 제공된 Doodle Crew Footer 컴포넌트를 `components/ui/doodle-crew-footer.tsx`에 추가하고 앱에 맞는 문구·색상·동작을 설정했습니다. 컴포넌트를 화면 최상단으로 옮겼으며, **번역하러 가기** 버튼은 메인 영역으로, 우측 하단의 **맨 위로** 버튼은 페이지 상단으로 이동합니다. 두 이동은 움직임 줄이기 설정을 따릅니다.
9. **Vercel 배포 준비** — 기존 로컬 서버의 요청 처리를 Vercel 서버리스 함수에서도 사용할 수 있게 분리하고 `api/index.js`와 `vercel.json`을 추가했습니다. 서버리스 환경의 메모리는 지속적인 누적 저장소가 아니므로 배포 환경의 토큰 현황을 브라우저별 저장 방식으로 변경했습니다.
10. **운영 배포 및 기능 확인** — Vercel에 `lingua-live` 프로젝트를 만들고 [운영 주소](https://lingua-live-ashy.vercel.app/)로 배포했습니다. 사용자가 Vercel Production 환경변수에 `GEMINI_API_KEY`와 `SUPABASE_SECRET_KEY`를 직접 설정한 뒤 재배포했습니다. 짧은 예문으로 영어·일본어·중국어 번역, WAV 음성 생성과 Supabase 저장 응답을 확인했습니다. 저장 확인 과정에서 `[배포 연결 테스트] 안녕하세요` 테스트 항목 한 건을 기록했습니다.

## Vercel 운영 환경

- 운영 주소: https://lingua-live-ashy.vercel.app/
- 주요 운영 환경변수: `GEMINI_API_KEY`, `SUPABASE_SECRET_KEY`. 프로젝트 URL은 `config.json`을 사용하며 `SUPABASE_URL`로 덮어쓸 수 있습니다.
- Vercel 환경변수를 추가하거나 변경한 뒤에는 새 배포가 필요합니다.
- 토큰 현황은 배포 환경에서 현재 브라우저 기준입니다. 실제 API 계정의 전체 사용량이나 청구액은 제공업체 대시보드에서 확인하세요.
- 링크에 접근할 수 있는 사람은 API 기능을 사용할 수 있습니다. 공개 범위를 확대하거나 사용자별 데이터를 분리하려면 별도의 인증과 접근 제어가 필요합니다.
